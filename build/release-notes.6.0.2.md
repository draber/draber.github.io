# 📦 Spelling Bee Assistant 6.0.2

**Release Date:** November 21, 2026

## Improvements

- The browser extension starts the Assistant as soon as the page is there, instead of waiting until everything has loaded.
- Escape closes the Genius screen and other full-screen messages.
- On phones, pop-ups use the full width, so the Grid has more room.
- New “Report a problem” in the menu, also available with Shift+Alt+B: opens a GitHub issue with a short technical report attached.
- Better at telling a slow page from a broken one.
