# 📦 Spelling Bee Assistant 6.1.0

**Release Date:** November 23, 2026

## Improvements

- The browser extension starts the Assistant as soon as the page is there, instead of waiting until everything has loaded.
- Escape closes the Genius screen, the Queen Bee screen and other full-screen messages.
- After a click in the Assistant, you can keep typing right away.
- On phones, pop-ups use the full width, so the Grid has more room.
- Better at telling a slow page from a broken one.
- Crisper icons.

## Fixes

- The page no longer freezes when two copies of the Assistant run at the same time, for example the browser extension and the bookmarklet.
